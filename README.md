# Árvore de pessoas — de Gênesis a Apocalipse

Uma única árvore interativa mostra pessoas bíblicas e suas conexões, da primeira família até João de Patmos. O diagrama carrega todas as pessoas ao abrir; não há abas de períodos nem nós de acontecimentos.

## Recursos

- Árvore completa de pessoas, com vínculos de descendência, parentesco, adoção ou discipulado identificados.
- Arraste com mouse ou toque para percorrer a árvore.
- Controles de zoom, pesquisa de pessoas, contador de visitas por navegador e painel com referências bíblicas.
- Catálogo tipado em `data/biblia.ts`, separado dos componentes.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Validação

```bash
npm run lint
npm run build
```
